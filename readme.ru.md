# Yuki System

Yuki System - это модульная экосистема с открытым исходным кодом для умных устройств, голосовых
помощников и интеграции с IoT.  
Она позволяет управлять множеством устройств (ПК, мобильными устройствами, умными колонками,
IoT-устройствами) через центральный сервер по единому протоколу.

> Этот README - краткий обзор. Подробное описание архитектуры, полный справочник по протоколу и
> модель безопасности - в [DOCUMENTATION.md](DOCUMENTATION.md) ([русский](DOCUMENTATION.ru.md),
> [日本語](DOCUMENTATION.ja.md)). Этот файл также доступен на [русском](readme.ru.md) и
> [日本語](readme.ja.md).

## Обзор

Yuki System состоит из нескольких модулей, каждый со своей ролью:

```text
yuki-system (мета-репозиторий / этот репозиторий)
        │
        ▼
yuki-core (сервер / мозг)
        │
        ├── yuki-protocol (протокол обмена данными и SDK)
        │
        ├── yuki-webui (веб-интерфейс)
        │
        └── Устройства (все клиенты подключаются через yuki-protocol)
              ├── yuki-device-pc (Windows)
              ├── yuki-device-pc-linux (Linux)
              ├── yuki-device-android
              ├── yuki-humidifier (умный увлажнитель на ESP32)
              ├── yuki-device-frame (FrameOS)
              └── yuki-speaker (умная колонка на ESP32)
```

## Компоненты

| Модуль | Роль | Описание |
|--------|------|-------------|
| `yuki-core` | Сервер / мозг | Маршрутизация команд, ИИ-обработка и управление устройствами |
| `yuki-protocol` | Протокол и SDK | Определяет форматы сообщений, типы команд и SDK для подключения устройств |
| `yuki-webui` | Веб-интерфейс | Позволяет пользователям следить за устройствами, отправлять команды и управлять автоматизацией |
| `yuki-speaker` | Умная колонка на ESP32 | Обеспечивает голосовой ввод/вывод, подключается к серверу |
| `yuki-device-pc` | Клиент для Windows | Выполняет команды сервера |
| `yuki-device-pc-linux` | Клиент для Linux | Тот же набор возможностей, что у `yuki-device-pc`, для настольных систем Linux |
| `yuki-device-android` | Клиент для Android | Выполняет команды и уведомления на Android-устройствах |
| `yuki-humidifier` | Умный увлажнитель на ESP32 | Wi-Fi увлажнитель, управляемый через сервер |

## Начало работы

Запустите `yuki-core`, затем `yuki-webui`, затем настройте нужные клиенты устройств - точные
инструкции по установке и запуску есть в README каждого модуля. Полное пошаговое руководство и
модель безопасности - в [DOCUMENTATION.md](DOCUMENTATION.md).
